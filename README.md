# Évolution des prix des céréales au Burkina Faso

## Question
Comment ont évolué les prix des céréales de base (mil, maïs, sorgho, riz) selon les régions et les saisons au Burkina Faso, et quelles zones sont les plus exposées aux hausses ?

## Données
WFP Food Prices for Burkina Faso — Humanitarian Data Exchange (data.humdata.org)
